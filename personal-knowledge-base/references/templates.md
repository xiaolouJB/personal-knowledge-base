# 模板集

所有产出严格按这里的模板写。模板存三处防丢：本文件、WorkBuddy 自动化提示词里、资料库《总索引与标签词表》文档的末尾——任一处被改，以资料库文档为准并同步其余两处。

## 正式笔记模板

```markdown
---
title: （标题：作者：主题，或平台+主题）
source: （原文链接；无外链时写来源形态，如「用户上传图片」「抖音视频文字稿」）
type: article | video | image | text
date_added: YYYY-MM-DD
tags: [标签1, 标签2]（最多 3 个，只能选自受控词表）
status: 完整 | 正文待补 | 部分待核实（有缺口才写这一行）
---

# （标题）

## 一句话总览
（一句话说清这条内容的核心）

## 原文整理
（忠实整理原文要点，保留关键数据、引用和出处，不掺评论。
原文摘录、用户笔记、AI 整理三类内容分开标注。）

## 核心摘要
1.
2.
3.（最多 5 条）

## 批判性点评
（逻辑漏洞、立场偏见、证据强度、与已知事实的出入；
没有明显问题就写「暂无明显硬伤」）

## 来源
（原文链接；无外链时注明来源形态）

## 相关条目
- 《已有笔记标题》——（一句话说清关系：互补 / 矛盾 / 同一方法在不同场景）
```

## 随感模板

```markdown
---
date: YYYY-MM-DD HH:MM
tags: [标签]（可选，最多 2 个，只能选自受控词表）
---

# 随感

（用户原话，一字不改，不润色）

## 备注
（记录时的上下文；与库内哪些条目有关联，链过去并说清关系）
```

## 每日复盘模板

```markdown
# 每日洞察复盘 YYYY-MM-DD

## 今日新增一览
- （标题）：一句话总览 [原文](链接)

## 条目之间的关联
（今天各条目之间、以及与历史笔记的关联）

## 观点碰撞
（不同来源说法矛盾或互补的地方，点名条目）

## 值得深想的问题
（2–3 个基于内容提出的问题，要具体，不要泛泛而谈）

## 随感回响
（今天的随感与知识条目的连接；无随感则省略本节）
```

## 周度复盘模板

```markdown
# 周度深度复盘 YYYY-MM-DD ～ YYYY-MM-DD

目标：深挖用户自己没注意到的东西，不做流水账。

## 本周主题分布
（按标签统计，哪些主题出现最多，简单解读）

## 你没注意到的关联
（跨条目的隐藏连接：看似无关的 A 和 B，其实在说什么相关的事，点名条目）

## 观点矛盾点
（本周内不同来源互相打架的地方，点名是哪些条目，各方证据强度如何）

## 关注重心漂移
（对比上周周报，用户的注意力往哪儿移动了）

## 盲区提示
（反复提到但没深入存的东西，或存得多但没消化的主题）
```

## 月度复盘模板

```markdown
# 月度深度复盘 YYYY-MM

目标：拉长时间看趋势和结构，不做流水账。

## 月度主题分布
（按标签统计 + 简单解读）

## 观点演变
（同一话题在一个月内观点如何变化，点名条目）

## 知识盲区
（用户关心但存得少的东西；存得多但没深挖的东西）

## 下月建议关注方向
（基于盲区和趋势，给 2–3 个具体建议）
```

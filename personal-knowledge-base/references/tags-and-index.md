# 受控标签词表 + 总索引维护

## 为什么要受控词表
标签一旦放任自创，很快会出现「AI」和「人工智能」两套同义标签，检索和复盘的主题统计就全乱了。所以：**只许用词表里的标签，一篇最多 3 个；要新增，先经用户同意，再把新标签写进本表。** 用户随手写的标签，先归一到词表里最接近的那个。

## 资料库文档《总索引与标签词表》怎么写
在资料库「个人知识库 / 99-索引与词表」文件夹下建一篇在线文档，命名《总索引与标签词表》。结构：

```markdown
# 总索引与标签词表

## 标签词表
（把上面的词表原样抄进来；这是全库标签的唯一权威版本）

## 时间线
- YYYY-MM-DD：《标题》——一句话总览（标签：x、y）
（每归档一篇，加一行，新的在上）

## 主题导航
- **自媒体**：《标题1》；《标题2》
（按标签分组，每组列出该标签下的全部笔记标题）

## 模板
（把 templates.md 的正式笔记模板原样抄在末尾——模板存三处防丢，这里是权威版）
```

## 更新规则
1. 每归档一篇正式笔记或一条随感：时间线加一行 + 主题导航对应标签下加标题。
2. 每完成一篇复盘：时间线加一行（标明是日/周/月复盘）。
3. 索引更新和笔记存回是同一个动作的两半：笔记存好了但索引没更新，算没完成，要在回报里说明。
4. 如果云端更新《总索引与标签词表》文档失败：把该加的索引行发在对话里，让用户手动贴进去，并明说失败，不许假装更新过。

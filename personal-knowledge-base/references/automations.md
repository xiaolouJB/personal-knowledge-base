# 三个自动化任务的提示词（粘贴到 WorkBuddy「自动化」里）

Skill 本身不带定时器。复盘靠 WorkBuddy 的自动化功能触发：建 3 个自动化任务，把下面对应段落原样粘贴为任务提示词。时间均为北京时间。

> 资料库版说明：知识库在 WorkBuddy 原生资料库的「个人知识库」空间里，读写走内置「资料库」skill（doc/manage 路由），存完必须回读节点复查。

---

## 自动化 1：每日复盘（每天 22:00）

```
你是我个人知识库的复盘员。知识库在 WorkBuddy 资料库的「个人知识库」空间里。

任务：生成今天的《每日洞察复盘》。

步骤：
1. 先读资料库「个人知识库 / 99-索引与词表」下的文档《总索引与标签词表》，确认受控标签词表。
2. 读今天（北京时间）新增的全部正式笔记和随感（按文档标题里的日期前缀判断）。
3. 按下面结构写复盘，必须与历史笔记对照找关联和碰撞，不只看今天：
   - 今日新增一览：每条一行「标题：一句话总览」，附原文链接
   - 条目之间的关联：今天各条目之间、以及与历史笔记的关联
   - 观点碰撞：不同来源矛盾或互补的地方，点名是哪几篇
   - 值得深想的问题：2–3 个，具体，不要泛泛而谈
   - 随感回响：今天随感与知识条目的连接；今天没随感就省略这一节
4. 铁律：复盘里每个观点都要能在库内笔记里找到出处，找不到就不许写；数字、结论不许编；当天没有新增内容，就只发一句「今天没有新增内容」并结束。
5. 把复盘创建成资料库「个人知识库 / 03-复盘」文件夹下的在线文档，标题「每日复盘-YYYY-MM-DD」（日期用今天）。
6. 存完自己再去资料库里回读这个文档，确认它存在、内容全；复查通过后，把复盘全文 + 文档链接发给我。存不进去或复查不到，就直接把全文发给我并明说「存入资料库失败，请手动保存」，不许说存好了。
```

## 自动化 2：周度复盘（每周六 09:00）

```
你是我个人知识库的复盘员。知识库在 WorkBuddy 资料库的「个人知识库」空间里。

任务：生成本周的《周度深度复盘》，不做流水账，只挖我自己没注意到的东西。

步骤：
1. 先读资料库「个人知识库 / 99-索引与词表」下的文档《总索引与标签词表》。
2. 读本周（上周六到本周五）新增的全部笔记和随感，并读上一篇周度复盘作对比基线；没有上一篇就说明是首篇。
3. 按下面结构写：
   - 本周主题分布：按标签统计，哪些最多，简单解读
   - 我没注意到的关联：跨条目的隐藏连接，看似无关的 A 和 B 其实在说什么相关的事，点名条目
   - 观点矛盾点：本周内不同来源互相打架的地方，点名条目，并比较各方证据强度
   - 关注重心漂移：对比上周，我的注意力往哪儿移动了
   - 盲区提示：我反复提到但没深入存的东西，或存得多但没消化的主题
4. 铁律：每个论断都要点名出处笔记；不许编造我没存过的观点。
5. 把复盘创建成资料库「03-复盘」文件夹下的在线文档，标题「周度复盘-YYYY-MM-DD」（日期用今天）；存完回读复查，复查通过后把全文 + 文档链接发给我；失败就发全文并明说存入失败，不许假装存好。
```

## 自动化 3：月度复盘（每月 1 日 09:00）

```
你是我个人知识库的复盘员。知识库在 WorkBuddy 资料库的「个人知识库」空间里。

任务：生成上个月的《月度深度复盘》，拉长时间看趋势和结构，不做流水账。

步骤：
1. 先读资料库「个人知识库 / 99-索引与词表」下的文档《总索引与标签词表》。
2. 读上个月新增的全部笔记、随感和当月的每日/周度复盘。
3. 按下面结构写：
   - 月度主题分布：按标签统计 + 简单解读
   - 观点演变：同一话题在一个月内观点如何变化，点名条目
   - 知识盲区：我关心但存得少的东西；存得多但没深挖的东西
   - 下月建议关注方向：基于盲区和趋势，给 2–3 个具体建议
4. 铁律：每个论断都要点名出处笔记；不许编造。
5. 把复盘创建成资料库「03-复盘」文件夹下的在线文档，标题「月度复盘-YYYY-MM」（上个月）；存完回读复查，复查通过后把全文 + 文档链接发给我；失败就发全文并明说存入失败，不许假装存好。
```

---

## 使用说明
- 三个任务建好后先各手动触发一次试跑，确认能读资料库、能按结构产出、能存回并复查，再开定时。
- 定时唤醒是否可靠，按 `library-setup.md` 第 6 步的隔夜验证结果为准；验证没过之前，不要对人宣称「全自动复盘」。
- 通知出口只有 WorkBuddy App / 小程序通知，没有个人微信直推——复盘全文以资料库里的文档为准，通知只是提醒。
